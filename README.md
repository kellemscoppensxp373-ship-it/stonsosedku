# tg-bot-orchestrator

Локальная панель инвентаризации и диагностики Telegram-ботов/каналов для Windows. Интерфейс работает на `http://127.0.0.1:8080`, данные хранятся локально в `data/state.json`.

> **Граница функциональности:** это безопасная панель учёта и диагностики. Она не регистрирует ботов через BotFather, не публикует сообщения и не автоматизирует/не распределяет реакции или другие действия, создающие искусственную вовлечённость. Для реакции и других действий используйте Telegram-клиент вручную. В реестр заносятся только метаданные — токены сервисных ботов не принимаются и не сохраняются.

## Быстрый старт (Windows)

1. Установите Python 3.11+ с python.org и отметьте **Add Python to PATH**.
2. Скопируйте `.env.example` в `.env`; задайте `ADMIN_ID` (числовой Telegram user ID). `CTRL_BOT_TOKEN` необязателен и нужен только для локальной проверки `getMe` управляющего бота.
3. Дважды щёлкните `start.bat`. Лаунчер создаст `.venv`, установит зависимости из `wheels/`, если там есть совместимые пакеты, иначе попробует PyPI, и откроет панель.
4. Для завершения закройте окно консоли.

## Настройка

- `WEB_HOST` по умолчанию `127.0.0.1`; приложение намеренно не слушает внешние интерфейсы.
- `WEB_PORT` — локальный порт панели (8080).
- `WEB_PIN` — необязательный PIN для доступа к REST API и WebSocket; задайте длинный случайный PIN, если на компьютере есть другие локальные пользователи. Статические файлы панели доступны без PIN.
- `CTRL_BOT_TOKEN` — опционально используется только при явном нажатии «Проверить Bot API»; храните `.env` в секрете.
- `ADMIN_ID` — числовой идентификатор владельца; зарезервирован для будущих локальных интеграций, не даёт удалённому пользователю доступ к панели.
- `MIN_REQUEST_DELAY` — минимальная пауза между разрешёнными диагностическими запросами.

Секреты не коммитьте. `.env`, данные, логи и сессии игнорируются Git.

## Панель и API

- Каналы и записи ботов: ручная инвентаризация, изменение и удаление метаданных.
- Диагностика конфигурации, живые события и санитизированные логи через WebSocket.
- `POST /api/diagnostics/bot-api` проверяет только токен управляющего бота через Bot API `getMe`; запрос начинается по явному действию пользователя.
- REST API и WebSocket требуют `X-Web-PIN` при настроенном `WEB_PIN`.

Запуск из командной строки: `python run.py`. Тесты: `python -m pytest -v`.

## Разработка и упаковка

Пакеты Windows wheel можно скачать на Windows/Python 3.11 командой из корня репозитория:

```powershell
python -m pip download -r requirements.txt -d wheels --platform win_amd64 --python-version 311 --only-binary=:all:
```

Если среда сборки не имеет доступа к PyPI, `wheels/README.txt` объясняет, как заполнить кэш на целевой Windows-машине.
